# CWLauncher

Лаунчер Minecraft Java для сервера Common World. Отдельная программа на Java 17: ставит выбранную версию игры, Fabric и моды сервера, при запуске проверяет обновления и запускает Minecraft.

Сервер по умолчанию: `commonworld.pterohost.ru:25965`. Версия игры по умолчанию: Minecraft 1.20.1 с Fabric.

## Как открыть проект

Клонируйте репозиторий и откройте папку `CWLauncher` в редакторе. Исходники лежат в `src/ru/cw/launcher`. Точка входа: `src/ru/cw/launcher/Main.java`.

Сборка готового `CWLauncher.exe` (нужен JDK 17):

```bat
powershell -ExecutionPolicy Bypass -File build-release.ps1
```

Готовая папка появляется в `FullLauncherCW`. Её нет в git целиком: внутри неё JRE и собранные файлы, их создаёт скрипт. В репозитории сохранён только фон `FullLauncherCW/assets/background/main.png`, чтобы сборка его не затёрла.

Запуск из исходников без упаковки в exe:

```bat
build.cmd
java -cp build ru.cw.launcher.Main
```

## Что делает лаунчер

- При запуске проверяет версию самого лаунчера, новости, список обновлений, версию модов внутри архива `modsCWL.zip` и файлы выбранной версии Minecraft.
- Если моды на сервере новее установленных, кнопка запуска меняется на «Обновить моды». По нажатию папка `mods` очищается, затем в неё ставятся новые моды.
- Если файлы Minecraft устарели, кнопка показывает «Обновить Minecraft»: скачивание начинается по нажатию, после него игра запускается.
- Обновление самого лаунчера вынесено в отдельную кнопку «Обновить лаунчер» и не подменяет кнопку запуска игры.
- Аккаунты Ely.by и локальные. У каждого аккаунта свой скин.
- В комплекте своя Java 17 для Minecraft. Для версий старше 1.17 по-прежнему нужна Java 8.

## Папки

| Путь | Назначение |
| --- | --- |
| `src/ru/cw/launcher` | Исходники лаунчера |
| `tests/SelfCheck.java` | Проверка, которая идёт вместе со сборкой |
| `build-release.ps1` | Сборка `CWLauncher.exe` |
| `icon` | Иконка окна и exe |
| `config/example-config.json` | Пример настроек |

Данные игрока лежат не в папке программы, а в `%APPDATA%\CWLauncher`: настройки, журнал, кэш и скины.
